# قائمة الأمان - Migo AI Video Agent Professional

راجعها قبل كل نشر. البنود المعلَّمة بـ [ ] لم تُختبر بعد من قِبل الوكيل (تحتاج Supabase حقيقي أو متصفحاً).

## أسرار ومفاتيح
- [ ] لا يوجد `service_role` أو أي مفتاح إداري في أي ملف يصل للمتصفح.
- [ ] `config.js` مضاف إلى `.gitignore` وغير مرفوع إلى GitHub.
- [ ] المفتاح المستخدم في الواجهة هو `anon/public` فقط.
- [ ] لا توجد كلمات مرور مخزّنة في `localStorage`.

## قاعدة البيانات و RLS
- [ ] نُفِّذ `database/schema.sql` ثم `database/policies.sql` بلا أخطاء.
- [ ] RLS مفعّل على كل الجداول الـ11.
- [ ] لا يستطيع مستخدم قراءة/تعديل صف يخص مستخدماً آخر (اختبار بحسابين).
- [ ] Storage buckets (`reference-assets`, `outputs`) **خاصة** (`public = false`).
- [ ] مسار كل ملف في Storage يبدأ بـ `auth.uid()`، والسياسات تمنع غير ذلك.
- [ ] لا يمكن الوصول إلى ملف خاص عبر رابط مباشر بلا جلسة.

## الدخول
- [ ] التسجيل العام (Signups) **معطّل**.
- [ ] حساب المالك أُنشئ يدوياً من Supabase Dashboard.
- [ ] استعادة الجلسة تعمل بعد إعادة تحميل الصفحة.
- [ ] حماية الصفحات الداخلية: لا يظهر المحتوى قبل التحقق من الجلسة.

## منطق التعلم
- [ ] الاقتراح الجديد يبقى `pending` حتى ضغط زر الاعتماد.
- [ ] الاقتراح المرفوض لا يصبح نشطاً أبداً.
- [ ] الاقتراح المعلّق لا يُستخدم في المشاريع الجديدة.
- [ ] عند تحديث قاعدة معتمدة تُعرض النسخة القديمة والجديدة والفرق.
- [ ] تحديث قاعدة ينتج اقتراحاً جديداً، لا تعديلاً صامتاً.
- [ ] سجل `learning_decisions` لا يُعدَّل ولا يُحذف بعد الإنشاء.
- [ ] استيراد نسخة JSON لا يُدخل اقتراحاتٍ كقواعد معتمدة.

## عزل المشروع عن المتجر
- [ ] المشروع في مستودع مستقل (`MigoAIVideoAgentProfessional`).
- [ ] لم يُعدَّل أو يُنقل أي ملف من مستودع متجر Migo AI Solution.
