# جرد النسخة السابقة (v1) وما سيؤول إليه

هذه النسخة السابقة وصلت مكتوبة في المحادثة (4 ملفات). الملفات الأصلية محفوظة عندك؛
هذا الجرد يضمن ألّا تُفقد أي وظيفة سليمة أثناء التطوير.

## ملفات v1
- `README-AR.md` — شرح عربي خطوة بخطوة (إعداد Supabase، النشر من Android، حدود FFmpeg).
- `index.html` — واجهة RTL: تسجيل دخول، استوديو مشروع، مكتبة، قسم تجميع فيديو.
- `styles.css` — تنسيق سينمائي أسود/كحلي/سماوي، متجاوب حتى 480px.
- `app.js` — المنطق: Supabase اختياري، DEMO_MODE، تقسيم مشاهد، نسخ البرومبتات، حفظ محلي/Supabase، دمج FFmpeg.wasm.
- `supabase-schema.sql` — **لم يصل** في المحادثة. مخطط v1 المعروف من الـREADME كان جدولاً واحداً (`video_projects`).

## جرد الوظائف في v1 → مصيرها في الاحترافية

| وظيفة v1 | الحالة في الاحترافية |
|---|---|
| واجهة عربية RTL سينمائية | تُحفظ وتُرحَّل إلى `index.html` + `styles.css` الجديدين |
| DEMO_MODE محلي | يُحفظ، ويُفصل بوضوح عن بيانات Supabase |
| دخول Supabase + تسجيل خروج | يُحفظ ويُبنى عليه في `js/auth.js` |
| إنشاء مشروع (عنوان/فكرة/مدة/أبعاد/أسلوب) | يُحفظ ويُوسَّع (هدف/جمهور) |
| تقسيم مشاهد `ceil(duration/10)` بحد 5 قوالب | **يُطوَّر**: 15/30/45/60/90/120 وثلاثة أبعاد، مدفوع بالإيقاع، ومجموع دقيق |
| نسخ برومبت مشهد/الكل | يُحفظ، ويُوسَّع (برومبت رئيسي + برومبت سلبي) |
| حفظ/تحميل المشاريع | يُحفظ، وينتقل لمخطط 11 جدولاً + RLS |
| دمج FFmpeg.wasm | يُحفظ ويُطوَّر إلى استوديو تجميع (ترتيب/معاينة/تقدم/بديل عند الفشل) |
| تحذيرات الأمان (service_role) | محفوظة ومكرّرة في `config.example.js` و`tests/security-checklist.md` |
